### 🏥 SwasthyaConnect
**Rural TeleHealth Access System**

A full-stack telehealth platform designed to bring remote healthcare to rural communities. Patients consult doctors via live HD video, check medicine availability, manage health records, and get AI-powered symptom assessments.

**Tech:** React 18 · Node.js · Firebase · Jitsi Meet · Google Gemini · Docker · Tailwind CSS · Framer Motion

- 📹 Video consultations via Jitsi Meet (HD, screen share, chat)
- 🤖 AI symptom checker powered by Gemini 2.5 Flash
- 💊 Medicine availability search across pharmacies
- 📋 Digital health records & prescriptions
- 📱 Progressive Web App (offline-ready, installable)

### 🔊 VoxGround / Vaani RAG
**Voice-First Multilingual RAG Model**

A voice-enabled Retrieval-Augmented Generation system with Hindi & Marathi support. Next.js UI backed by FastAPI for RAG, speech-to-text, and text-to-speech via Sarvam AI.

**Tech:** Next.js · TypeScript · FastAPI · Python · Sarvam AI · Docker · Vercel

[![Live Demo](https://img.shields.io/badge/Live%20Demo-00BFFF?style=for-the-badge&logo=vercel&logoColor=white)](https://voice-enabled-rag-model-7o48.vercel.app/)
[![GitHub](https://img.shields.io/badge/Source-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/AdarshYadav9/Voice_Enabled-RAG-Model)

**Key Features:**
- 🎙️ Voice input with multilingual STT (Hindi + Marathi)
- 📚 RAG pipeline for context-aware responses
- 🔈 Text-to-speech output via Sarvam API
- 🐳 Docker + Vercel production-ready deployment
